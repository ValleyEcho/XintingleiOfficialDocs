# 服内称号获取

请先登录 [新亭泪用户中心](https://title.xintinglei.cn/)   

在账户中领取**积分**

每**60分钟**的游戏在线时长可以获取**1点积分** *(暂定)*

**积分**可用于在**称号商店**中购买**称号** 或者创造**自定义称号**
*（称号价格由称号站管理；购买或领取后会永久加入当前账户库存）*

## 注意
可以在[这里](https://mcg.tuanzi.ink/)编辑好你的自定义称号喵

称号字数**不能大于9个字**

颜色符号格式不要使用`§`，请使用`&#`

例如`&#b993d6梦&#aa99d8游&#9ba0d9世&#8ca6db界`就是一个正确格式的称号
