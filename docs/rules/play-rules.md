# 游玩规则

1. 请勿在游戏中随意辱骂他人，恪守道德底线


2. 请勿在未获得他人允许的情况下进行PVP


3. 请勿随意破坏他人建筑、机器


4. 请勿随地乱放假人，机器挂完记得下假人


5. 请勿制造恶意卡服机，


6. 高效率机器(百万级及以上)开机前请确保服内没有其他正在运行的大型机器，避免炸服


7. 严禁在服内建造违反中华人民共和国法律法规的建筑


8. 严禁在服内发送违反中华人民共和国法律法规的消息/内容
    
9. 严禁在服务器内使用外挂、利用漏洞等影响游戏公平性的行为，

若您违反上述条例管理组将视情节严重程度给予**有限期封禁或永久封禁处理**等相应处理

最终解释权归新亭泪管理组所有
