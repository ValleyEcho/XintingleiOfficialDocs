# 抽奖活动  

### 彩票机制：
**1.普通彩票**

通过游玩活动地图可以获得积分，达到阶段积分即刻获得一次普通抽奖机会

每次普通抽奖机会生成一张普通彩票，最多可获得四张普通彩票：

```
示例：
票号：XT-N-2026-917813
主号码：03 07 11 14
纪念号：05
```

**2.普通彩票号码规则**

- 主号码：从 `01–14` 中随机抽取 4 个，不重复。
- 纪念号：从 `01–06` 中随机抽取 1 个。
- 每个账户最多拥有 4 张普通彩票。
- 彩票生成后不可修改或重新随机。


**3.特别彩票**

玩家获得第一张普通彩票后，自动获得一张特别彩票：

```
示例：
票号：XT-S-2026-114514
```

**4.特别彩票规则：**

- 每个账户最多一张
- 不消耗普通抽奖机会
- 特别票号用于抽取特等奖奖品

## 开奖流程：
到达开奖时间后，玩家进入周年庆页面手动开票，并查看自己获得的奖品

### 1.普通号码开奖

网站在开票时间生成本期开奖号码
- 四个主号码
- 一个纪念号码
- 一个独立专属票号

号码命中代表取得相应等级奖品的优先候选资格，但最终分配不超过该等级的实际库存。

如果同一等级的命中彩票数量超过奖品库存，则在这些命中彩票中随机选择对应数量的候选票分配奖品  
### 2.特别彩票开奖
在所有获得特殊彩票的玩家中抽取一名玩家获得特等奖
### 3.候选奖品分配
- 先根据号码命中结果分配一至四等奖候选
- 如果某个等级没有足够的普通彩票命中奖品，导致奖品剩余，则把这些剩余奖品随机分配给尚未获得候选奖品的普通彩票
- 每张普通彩票最多对应一个候选奖品
- 一个玩家有多张普通彩票时，可能开出多份候选奖品

**如果一个玩家的多张普通彩票开出了多份候选奖品：**

- 玩家只能选择保留其中一份
- 在选奖截止时间前可以修改选择
- 玩家可以根据个人喜好选择，不强制选择等级最高的奖品
- 未被选择的其他候选奖品会被释放

**如果玩家没有开票或没有主动选择：**

- 系统会在选奖截止时**自动保留等级最高的一份**
- 同等级有多份时，由封存的随机结果**确定其中一份**
- **不会因为玩家忘记操作而失去所有奖品**

### 4.最终补抽规则
**若奖品分配后仍过剩：**
- 在尚未获得一至四等奖的账号中进行最终补抽
- 每张未获奖的普通彩票算一份抽取权重。
- 依据权重进行各等级奖品的补抽
- 每个账号最终最多获得一份一至四等奖。
- 特等奖得主如果还没有普通奖，仍然可以参加最终补抽。

### 5.参与奖保底
最终补抽完成后，所有没有获得一至四等奖的参与账号，按库存发放小亚克力挂件。

### 6.奖品发放
在活动结束后各位获奖玩家私信提供收货地址，奖品将由新亭泪管理组寄货发放

# 积分获取
## 活动一：僵尸末日
该小游戏是hypixel僵尸末日游戏的阉割版，但保留了大部分玩法，波数改为**无限波**，同时**难度略为降低**

### 介绍
**游戏目标**：游戏采用波次生存制，你需要和最多3名队友合作，尽可能抵御不断来袭的僵尸。

**游戏失败**：如果所有队员同时死亡，游戏即告失败。

**抽取地图**：**穷途末路、坏血之宫**

###  基础玩法与机制
游戏开始后，每位玩家会配备一把手枪和一把刀。你需要通过以下方式来强化自己：

**获取金币**：击杀僵尸（每只+10）或修复被破坏的窗户（每块木板+10）都能获得金币。

**消费与探索**：金币主要用于解锁新区域、购买新武器和增益。

**启动电源**：在地图深处找到并花费金币启动**电源开关**，这是解锁大部分高级机器和增益的必要条件

### 游戏改动
**难度增强**  
后期回合会适当提高普通僵尸生命值和攻击伤害，多人时生命值也会提高；没有增加刷怪数量，Boss基本保持原有血量。

**取消怪物受伤冷却**  
Zombies怪物的受伤冷却降到1 tick，使枪械连射伤害更容易正常结算；不修改玩家受伤无敌帧。

**卡关保护**  
如果计数剩余不超过3只、场内实际没有有效僵尸，并持续30秒没有进展，会自动跳到下一关。  

玩家投票跳关
一关进行满**180秒**后，玩家可以输入：
``` 
/zg vote 或 /zvote
```

投票**持续30秒**，需要当前存活玩家**60%**同意。通过后清理该关残留怪物并进入下一关。

### 积分规则

每击杀**1只僵尸**可获得**1积分**，采用累积制，多局累计积分  

**以下情况不计入成绩：**
- 玩家中途退出。
- 管理员手动停止。
- 服务器崩溃或异常关闭。
- 没有产生正常结束事件的对局。

您在游戏中获得的积分可用于**兑换普通彩票**
