# 入服步骤

1.通过新亭泪的审核

2.使用[新亭泪皮肤站](https://skin.xintinglei.cn/)注册你的皮肤站账号
 >注册时需要邀请码，找管理要一个就行 
 > 
 >注册时务必与你原本的游戏id一致(不论正版/离线)

3.下载[新亭泪客户端](https://docs.xintinglei.cn/guide/XintingleiClient-ver-Rosa.html)并根据[教程](https://docs.xintinglei.cn/guide/XintingleiClient-ver-Rosa.html#%E5%AE%89%E8%A3%85%E6%95%99%E7%A8%8B-windows-pcl)安装
 >安装时请使用整合包内**自带**启动器

4.登录你的新亭泪皮肤站账户，启动游戏将会自动加入服务器
